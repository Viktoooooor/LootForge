Welcome to LootForge

LootForge is an unofficial tool. It talks to the League client running on this PC and sends the same requests the client's own loot screen sends.

  • Everything is real. Opening, disenchanting, unlocking, rerolling and buying change your actual account and cannot be undone. LootForge asks before anything irreversible.
  • It stays on your PC. The app only listens on 127.0.0.1. Your client token never leaves this computer.
  • No cheats. No injection, no memory reading, no game file changes.
  • Use at your own risk. The League client API is not officially supported by Riot Games and can change at any time.
